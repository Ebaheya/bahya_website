## 🧠 Overview

A **modern, responsive Admin Dashboard UI** built with Flutter Web  
for managing psychosocial care workflows for breast cancer patients.

> Designed for real-world medical environments with clean UX and high usability.

---

## 🎯 Why This Project?

Breast cancer patients often experience:
- Anxiety 😟  
- Depression 😞  
- Emotional distress 💭  

This dashboard helps healthcare teams:

✔ Track patient mental health  
✔ Monitor progress over time  
✔ Detect high-risk cases instantly  
✔ Improve response time
